# 30 张合成名片 OCR 基准测试

测试时间：2026-11-03  
设备：iPhone 17 Pro 模拟器，iOS 26.4（仅启动这一台模拟器）  
测试集：`TestData/BusinessCardDataset` v1.0.0  
流水线：矩形检测与透视校正 → Vision OCR（`zh-Hans`、`en-US`）→ `BusinessCardFieldParser`

## 结果摘要

| 指标 | 结果 |
|---|---:|
| 完成处理 | 30 / 30 |
| 流水线异常 | 0 |
| 非空 OCR | 27 / 30（90.0%） |
| 触发透视校正 | 25 / 30（83.3%） |
| OCR Ground Truth 值召回 | 187 / 224（83.5%） |
| 非空字段解析准确率 | 140 / 224（62.5%） |
| 全字段准确率（含空字段） | 186 / 270（68.9%） |
| 缺失字段保持为空 | 46 / 46（100%） |
| 总耗时 | 29.151 秒（平均约 0.972 秒/张） |

“OCR Ground Truth 值召回”表示 Ground Truth 中的非空字段值是否出现在 OCR 原文中；“非空字段解析准确率”表示解析后的结构化值是否与 Ground Truth 归一化后完全一致。全字段准确率会受到空字段真阴性的提升，因此主要质量指标应看非空字段解析准确率。

## 按难度

| 难度 | OCR 值召回 | 非空字段解析准确率 |
|---|---:|---:|
| Easy | 32 / 45（71.1%） | 26 / 45（57.8%） |
| Medium | 77 / 86（89.5%） | 56 / 86（65.1%） |
| Hard | 78 / 93（83.9%） | 58 / 93（62.4%） |

Easy 低于 Medium/Hard 并不是难度标签失效，而是当前边缘检测会在部分平整名片中误选内部色块或单侧栏，导致校正后只保留一部分名片。

## 按字段

| 字段 | OCR 值召回 | 非空字段解析准确率 |
|---|---:|---:|
| 姓名 | 27 / 30（90.0%） | 26 / 30（86.7%） |
| 公司 | 25 / 28（89.3%） | 7 / 28（25.0%） |
| 职位 | 25 / 28（89.3%） | 18 / 28（64.3%） |
| 手机 | 24 / 30（80.0%） | 24 / 30（80.0%） |
| 座机 | 15 / 21（71.4%） | 15 / 21（71.4%） |
| 传真 | 10 / 14（71.4%） | 10 / 14（71.4%） |
| 邮箱 | 22 / 28（78.6%） | 22 / 28（78.6%） |
| 网站 | 18 / 21（85.7%） | 18 / 21（85.7%） |
| 地址 | 21 / 24（87.5%） | 0 / 24（0%） |

地址和公司的 OCR 召回较高，但结构化准确率明显偏低，说明主要瓶颈是字段解析而不是字符识别。地址解析目前保留了 `地址 / Address:` 标签，无法与只包含地址值的 Ground Truth 精确匹配；公司启发式没有覆盖 `Lab`、`Labs`、`Works`、`Consulting`、`Ventures`、`Systems` 等测试集用词。

## 无文本样本

- `card_005`：`clean_dark_card`
- `card_023`：`occluded_corner`
- `card_030`：`perspective_shadow_clutter`

另外，`card_002`、`card_008` 和 `card_020` 的 OCR 只保留了姓名侧内容。结合 25/30 的高校正触发率，可见当前矩形检测在分栏、深色背景、遮挡和杂物场景中容易把内部区域识别成完整名片边界。

## 自动化入口

测试实现位于 `CamCardReplicaTests/BusinessCardDatasetTests.swift`。测试集只复制到单元测试 Bundle，不进入 App 安装包。每次运行会在 xcresult 中附加完整 JSON 报告，并逐张记录识别原文和字段对比。

```bash
xcodebuild \
  -project CamCardReplica.xcodeproj \
  -scheme CamCardReplica \
  -destination 'platform=iOS Simulator,OS=26.4,name=iPhone 17 Pro' \
  -only-testing:CamCardReplicaTests/BusinessCardDatasetTests/testThirtyCardDatasetOCRBenchmark \
  test
```

本基准测试只把“30 张全部完成且无异常”作为 XCTest 通过条件，不用当前准确率作为硬编码阈值，避免后续算法改进前由测试数据标签变化造成虚假回归。准确率变化应通过报告进行比较。
