# 阶段 5 真机拍摄与透视校正

完成日期：2026 年 11 月 2 日

## 真机相机

- 使用 AVFoundation 建立后置广角相机 `AVCaptureSession` 和实时预览。
- 首次进入拍摄页时请求相机权限；拒绝后给出系统设置入口，不绕过权限。
- 使用 `AVCapturePhotoOutput` 输出高质量照片，并在设备支持时启用自动闪光。
- 拍摄完成的数据直接进入已有导入会话，不写入系统相册，也不上传网络。
- 工程生成的 Info.plist 已加入 `NSCameraUsageDescription`。
- 模拟器无法访问实体相机，因此继续使用相册入口；UI 测试仍使用固定合成图片，避免伪造相机硬件结果。

## 边缘检测与校正

相册和真机照片统一执行以下本地流水线：

```text
图片数据
  → Vision VNDetectRectanglesRequest
  → 选择可信度最高的名片四边形
  → Core Image CIPerspectiveCorrection
  → JPEG 输出
  → Vision OCR
  → 字段解析与人工核对
```

检测器限制最小面积、置信度、宽高比和四边形容差，减少把背景物体误识别为名片。未检测到可信四边形时直接保留原图；检测成功但渲染失败时同样回退原图，OCR 流程不会因校正失败而中断。

核对页显示最终处理后的图片。若自动校正成功，会显示“已自动检测边缘并校正透视”；裁剪图标可查看本次检测状态和重新拍摄建议。
